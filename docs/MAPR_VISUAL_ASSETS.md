## Hero illustration

The public file is `public/images/mapr-hero-assessment.svg`. Its layout size is 1200 × 900 pixels (4:3). The drawing coordinates use a tighter view of the same scene so the neighborhood sits in the right side of the hero. The page loads it from the application origin. It does not call Higgsfield at runtime.

This illustration was drawn in the repository as SVG. It was not generated by Higgsfield.

Higgsfield CLI 1.2.2 was inspected before that decision:

- `higgsfield workspace status` reported “No workspace selected.”
- `higgsfield account status` returned the same error and hinted at `workspace set`.
- `higgsfield workspace list` showed one workspace, named Private, on the free plan, with 0 credits. It was not selected.
- `workspace set` was not run. Credits were not purchased and the plan was not changed.
- No generation job was created, so there is no job id, model id, or download URL.
- No project file, resident record, geospatial file, signature, or environment value was uploaded.

The intended still-image brief, not submitted, was:

> Create a premium, minimal isometric editorial illustration for a civic disaster-assessment web application. Show a small abstract neighborhood of white buildings with blue roof accents, a subtle geographic selection outline, a blue location marker, and a restrained inspection/checklist motif. Use a pure white background, cobalt blue and light sky-blue accents, soft neutral shadows, clean geometry, and generous negative space. Compose the main objects toward the center-right so the image works beside a left-aligned website headline. Calm, trustworthy, precise, contemporary, and suitable for a public-service research application. No text, lettering, numbers, logos, seals, people, casualty imagery, dramatic destruction, satellite photographs, or realistic claims about actual locations. Wide landscape composition, approximately 4:3.

The SVG follows that brief: white buildings, cobalt and sky-blue roofs, a dashed selection outline, a blue location marker, and a checklist card, placed toward the center-right on a white field. It contains no text.

MapR’s damage-classification model remains fine-tuned EfficientNetB0 with AdamW. This file is promotional artwork only.
